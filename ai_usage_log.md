## One thing the generated script did that you would not have thought to specify, and whether it was correct or needed adjustment
- Rate limiting when using information from the SEC. The SEC caps traffic at 10 requests per second before blocking IP addresses. Claude capped time waited between each search at 0.2 which abides by the 10 searches per second. Therefore the script cannot get the IP temporarily banned and causing the information searching to be longer. I was unaware of this rate cap, and it was good that Claude caught it.
